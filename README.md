# 设备管家 Butler Console

电脑控制安卓设备的本地控制台：无线连接、屏幕监看、远程触控、遥控按键、应用安装卸载、文件互传。数据与连接全部在本机，无云端、无上传。

## 快速开始（Windows 桌面版）

1. 双击 `启动设备管家.bat`，浏览器自动打开控制台（本机 8970 端口）
2. 手机上开启「开发者选项 → 无线调试」
3. 首次使用先配对（电脑命令行，每台手机一次）：

```
host\bin\adb.exe pair 手机IP:配对端口 配对码
```

4. 回到页面，把「无线调试」页显示的 `IP:端口` 填入地址栏，点「连接」
5. 连接成功后：中间出现设备实时画面（截图轮询），点击画面即远程触控

> 也可控制电视盒子 / 平板等任何开了无线调试（或 adb 网络调试）的安卓设备。

## 功能一览

| 模块 | 说明 |
|---|---|
| 无线连接 | adb 无线调试直连；状态灯常亮绿 = 在线 |
| 屏幕监看 | 截图轮询（0.3~3 秒可调），点画面 = 远程点按 |
| 遥控台 | 方向键/OK、主页/返回/菜单/任务、音量、电源、文字输入 |
| 应用管理 | 拉取第三方应用列表、搜索、安装 APK、卸载 |
| 文件互传 | 本机文件推送到设备 `/sdcard/Download/`；从设备拉文件到本机 |

## 架构

- `docs/index.html` —— 控制台界面（单文件，桌面三栏 / 手机窄屏自适应）
- `host/server.py` —— Python 标准库实现的本地服务，封装 `host/bin/adb.exe`，仅监听 127.0.0.1
- `host/bin/adb.exe` —— 内置 adb（含运行库），无需另装 platform-tools
