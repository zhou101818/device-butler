连接方式

在手机上打开「开发者选项 → 无线调试」，点「使用配对码配对设备」或直接开启端口。把显示的 IP:端口 填到上方地址栏后连接。
首次配对请在电脑命令行执行：
adb pair IP:配对端口 配对码
